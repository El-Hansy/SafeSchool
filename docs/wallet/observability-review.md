# Wallet Observability Review

Wallet audit events are emitted for wallet activation/status changes, ledger posting, top-up initiation, cashier credit, payment confirmation receipt, merchant creation, rule setting changes, and reconciliation workflows. The feature includes typed audit event records, event categories, event types, subject references, actor references, reasons, and correlation fields.

Operational review points include payment confirmation status, POS purchase decisions, offline sync batch counts, spending-limit denials, anomaly status, reconciliation mismatches, retention holds, and guardian-visible issue counts.
