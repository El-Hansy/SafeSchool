# Phase 12 Mobile

Phase 12 delivers one production role-based mobile app with controlled APK
release. Guardian access is a role and permission inside the same app, not a
separate parent app.

## Coverage

- Guardian and student journeys
- Transport driver, gate/access, canteen cashier, teacher, medical staff,
  complaint handler, communication sender, document administrator, school
  administrator, and platform support workspaces
- Arabic and English with RTL validation
- Controlled APK release, audience, version, checksum, and support evidence
- Offline queues only for approved source workflows
