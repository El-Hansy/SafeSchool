# AttendanceAccess Observability Review

- Scan outcomes emit audit categories for accepted, denied, flagged, duplicate,
  and review-required scans.
- Attendance generation preserves scan evidence and correction reason.
- Notification suppression records guardian eligibility reasons.
- Anomaly detection records severity, status, evidence reference, assignment,
  and resolution reason.
- Offline sync keeps client batch and local scan time evidence for review.
